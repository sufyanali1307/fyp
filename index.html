Deployment Flow
  1. Choose files, a GitHub repository, generated code, or an ML model.
  2. NexusCode creates an environment record and prepares the project workspace.
  3. The deploy action builds and starts the Docker container through the backend.
  4. The dashboard monitors status, live URL, and logs for the running environment.
API Reference
GET/api/environmentsList environments
POST/api/environmentsCreate environment
POST/api/environments/{id}/deployDeploy container
GET/api/environments/{id}/logsRead live logs
DELETE/api/environments/{id}Delete environment
Operational Notes
  • Public browsing remains open for visitors without an account.
  • Frontend account state is local to this browser until backend auth is added.
  • Running environments expire after the configured backend lifetime.
  • Private GitHub repositories require backend token support before production use.
